## 部署注意

Nginx 模板新增 `error_page 404 /404.html`，并保留 HTTP 404 状态。旧服务器只执行 `deploy:update` 不会更新 Nginx 配置，因此自定义错误页需要一次完整部署才能启用。GitHub Pages 使用构建根目录的 `404.html`。

最终本地 `dist/` 恢复为正式域名根路径构建。`output/playwright/optimization-*.png` 保留本地界面截图，不作为站点内容发布。

## 后续建议，按优先级推进

| 优先级 | 建议 | 原因与验收方向 |
| --- | --- | --- |
| 高 | 补充真实公开联系方式与可下载简历 | 当前保留已知 GitHub / CSDN；需要作者提供真实信息，再检查 mailto 与 PDF 可访问性 |
| 高 | 为代表项目补 1–2 张脱敏截图或流程图 | 目前文字较密；用“问题—方案—结果—证据”帮助读者快速理解，图片需要替代文本、明确尺寸与压缩 |
| 中 | 收敛首页后半段重复信息 | 代表项目、具体工作事项和实践记录有交叉；结合阅读反馈决定合并哪部分，避免仅凭观感删除有效内容 |
| 中 | 显式约束依赖版本并建立升级节奏 | `package.json` 仍使用 `latest`；当前靠 lockfile + npm ci 复现，后续升级应同时验证 Astro、MDX、TypeScript 兼容性 |
| 中 | 增加分享封面与结构化数据 | 本轮完成基础元信息；下一步可统一 OG 图，并为文章补真实作者、日期等 JSON-LD 字段 |
| 中 | 增加真实移动设备性能与键盘可访问性审查 | 本轮覆盖桌面浏览器视口与关键交互，尚未测量线上 LCP / INP / CLS，也未完成完整无障碍审计 |
| 低 | 内容变多后再引入全文搜索 | 当前 33 条记录适合静态标题 / 摘要 / 标签筛选；正文检索需求明确后评估 Pagefind 等构建期索引 |
| 低 | 增加内容迁移重定向和外链巡检 | 改文件名可能破坏外部引用；维护旧 URL 映射，并定期核对 Skills 的上游分支、命令与版本 |

暂不引入评论、账号系统、数据库或大型客户端框架；这些需要明确的读者需求与维护预算。
