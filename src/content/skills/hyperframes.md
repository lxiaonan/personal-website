## 它是干什么的

HyperFrames 是把 HTML、CSS、媒体素材和可定位时间的动画合成为视频的框架。配套的 `hyperframes` Skill 是创作入口：理解你想交付什么，读取现有项目状态，选择合适的工作流，再组织创意、素材、动画、预览和渲染能力。

它适合有明确布局、文字、图表和节奏的内容，例如产品发布片、项目介绍、功能演示和动态数据说明。输出既可以是 MP4，也保留可编辑的工程，后续修改标题、数据、时长和品牌样式更方便。

## 它能做哪些内容

- **产品与项目介绍。** 把产品卖点、页面素材和行动入口组织为多个镜头。
- **技术功能演示。** 结合代码片段、界面、说明文字和旁白讲解变化。
- **动态信息展示。** 用图表、数字、时间线等解释业务数据。
- **字幕与素材编排。** 在已有素材基础上组织字幕、配乐、转场与画面节奏。

具体能力由入口路由到对应工作流。当前上游已将创作、核心合成、动画、音频、素材和 CLI 拆成多项 Skill，安装核心集后再按任务加载。

## 安装与开始

准备 Node.js 22+、FFmpeg 和支持 Skill 的 Agent。推荐按上游方式安装核心集：

```bash
npx hyperframes skills update
```

喜欢交互选择的用户，也可以执行下方命令，在界面中选择 Core Skills：

```bash
npx skills add heygen-com/hyperframes
```

这两种方式选择其一即可。无需为了做一个介绍片，把所有专题工作流都提前装齐。

## 一份足够清楚的创作需求

```text
使用 hyperframes，为 Java 后端个人网站做一个 15 秒的中文项目介绍片。
受众：招聘方和对后端工程感兴趣的开发者。
画幅：1920×1080，横屏；风格沿用网站的蓝色、深色背景和简洁排版。
内容：开场介绍身份，中段展示批量投放、BI 分析和 AI 创作平台，结尾给出网站地址。
素材只使用我提供的页面截图和项目资料，不虚构业务指标。
先给脚本与分镜，再制作可预览工程；最终预览确认后导出 MP4。
```

比起“做一个炫酷视频”，明确受众、片长、画幅、内容和素材，会让 AI 更容易选择正确流程。没有背景音乐或配音素材时，也应说明是否需要生成、是否接受额外服务以及期望语言。

## 一次创作如何推进

1. **读现状。** 已有项目优先读取简报、分镜和工程状态，避免每次重新询问或重建。
2. **定目标。** 新项目确认受众、用途、风格、时长与交付格式。
3. **出脚本和分镜。** 把每段表达内容与时间、画面、字幕、音轨对应起来。
4. **组织工程。** 使用合成、动画、素材等配套能力，写出可以按时间定位的画面。
5. **检查与预览。** 通过 CLI 检查运行问题，同时观看关键帧、字幕与音画关系。
6. **确认与导出。** 最终预览确认后渲染，核对成片与工程，并记录尚未解决的限制。

## 和一般的视频生成工具有什么区别

它主要通过可编程的网页画面和素材组织视频，因此适合精确排版、稳定字体、品牌复用、图表和界面说明。它可以配合图片、语音或视频生成服务使用，但自身不意味着“输入一句话就能获得任意写实场景素材”。

对于个人网站，可以先做一个短片模板，把项目名、介绍、截图和链接作为可替换内容。将来更新项目时修改工程，再重新渲染，通常比重新剪一整条片更容易维护。

## 与 hyperframes-cli 怎么配合

从“我想做一条什么视频”开始，使用 `hyperframes`。已经有工程，只需要运行检查、启动预览或导出文件，交给 `hyperframes-cli`。入口负责创作流程，CLI 负责具体执行与诊断。

## 使用边界

成片质量依赖脚本、素材、动画和审阅。AI 不能代替你确认项目事实、图片版权、字体授权或音乐使用范围。长片与复杂场景可能需要更多渲染时间；先制作几秒小样，确认视觉方向和机器环境后再扩展。
